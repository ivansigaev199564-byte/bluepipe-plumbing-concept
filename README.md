# BluePipe Plumbing — Website Concept

A multi-page website concept for a local plumbing company, designed and built as a **portfolio piece**.

> This is a demo concept: the company, reviews, and contact details are fictional, and the request form does not send data.

## Pages

- **Home** — hero, trust bar, services, testimonials, service areas, process
- **Services** — full service grid, process steps, pricing promise, FAQ
- **About** — story, core values, team, credentials, local commitment
- **Reviews** — Google-style reviews, before/after customer spotlight
- **Service Areas** — coverage map, cities, neighborhoods, FAQ
- **Contact** — service request form, contact info, map, FAQ

## Tech

- Vanilla HTML / CSS / JS — no frameworks, no build step
- Scroll-reveal animations (IntersectionObserver), animated counters, micro-interactions
- Fully responsive (desktop / tablet / mobile), `prefers-reduced-motion` friendly
- Fonts: Plus Jakarta Sans + Inter (Google Fonts)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8765
```
